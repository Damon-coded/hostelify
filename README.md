# Hostelify

**Hostelify** is a smart and lightweight hostel allocation system built to make the traditional hostel allocation process simpler, faster, and completely digital.

Usually, hostel allocation involves a lot of paperwork, manual data handling, checking student details, managing room availability, calculating priorities, and keeping track of allotments. We built Hostelify to bring all of these things together in one place and reduce the amount of manual work involved.

The system has separate interfaces for **students and administrators**. Students can register, complete their hostel application, choose their preferences, and check their allocation status. On the other side, administrators get a control panel where they can manage applications, monitor hostel and room occupancy, generate priority lists, run the allocation process, and publish the final results.

The main idea behind Hostelify is to make the allocation process more organized and less dependent on manual calculations. The system uses different student and hostel-related factors to create a priority order and allocate available rooms according to the defined rules. It also handles things like hostel preferences, academic details, location/region information, room availability, and allocation status.

For the backend, we used **Google Apps Script** along with **Google Sheets**. Apps Script handles the server-side logic and connects the frontend with the data, while Google Sheets works as the database for storing student, hostel, room, and configuration information. This allowed us to build a functional backend without setting up a separate server or database infrastructure.

The frontend is built using **HTML, CSS, and JavaScript**, with a focus on keeping the interface simple and easy to use for both students and administrators.

### What Hostelify aims to achieve

* Reduce paperwork and manual effort
* Make hostel applications completely digital
* Simplify the allocation process
* Reduce repetitive administrative work
* Keep student and room data organized
* Make room availability easier to track
* Provide a centralized platform for students and administrators
* Make the overall process faster and more transparent

Hostelify is currently a **working prototype**, and there is plenty of scope to take it further with features such as notifications, document verification, hostel fee management, room-change requests, advanced analytics, and a more scalable database/backend.

We built Hostelify with a simple idea in mind:

> **Why manage hostel allocation manually when the entire process can be made digital?**
